# Agentic SDLC Prototype — URL Shortener

The submission package contains the agent source code, evaluations, tests, examples and reviewer instructions.

## Download and get started

1. **[Download Schwab-Submission.zip](https://github.com/raamkrishnet/agentic-sdlc-url-shortener/releases/download/v1.0-review/Schwab-Submission.zip)**.
2. Extract the ZIP into a new folder on your Windows machine.
3. Open **README.md inside the extracted Schwab-Reviewer folder**.
4. Follow that README in order.

The packaged README provides complete examples for:

- Installing Python dependencies and Docker.
- Configuring your OpenAI API key and model.
- Entering requirements and approving plans.
- Generating, testing and deploying a service locally.
- Testing greenfield, brownfield and ambiguous requirements.
- Running evaluations and reviewing results.

For explanations of the project’s files and folders, see **FILE_GUIDE.md** in the same folder.

Live generation requires your own OpenAI API key and credits. No API key is included. The package also provides checks that make no OpenAI calls.

Prototype scope and known limitations are documented inside the package.
